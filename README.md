### 🛠️ Projects

**[Cycle & Mood Tracker](https://github.com/daniellaseberini/mood-cycle-tracker)** — [live demo](https://mood-cycle-tracker.vercel.app)

**The motivation:**
I wanted to understand my own patterns — how sleep, diet, and cycle phase actually affect my mood — without handing that data to an app company. So I built a tracker where everything stays on your device: no account, no server, no analytics.

**What it does:**
Daily logging (mood, sleep, diet, symptoms), a computed wellness score with transparent weighting, trend insights by cycle phase, and period prediction. Local-first PWA; friends and family use it too.

**[FODMAP Scanner](https://github.com/daniellaseberini/fodmap-scanner)**

**The motivation:**
Eating plant-based with a sensitive gut means constantly checking whether ingredients are high-FODMAP — I was doing the same lookups over and over. So I automated my own habit.

**What it does:**
Scan a meal by photo or text and get a FODMAP score, plus an AI chat assistant for gut-health questions.

**[Article to Audio](https://github.com/daniellaseberini/article-to-audio)**

**The motivation:**
I kept saving articles I never got back to reading. This turns them into something I can listen to instead.

**What it does:**
Paste an article URL, and the extracted text is converted to speech via the ElevenLabs API, returned as a playable, downloadable narration. Flask backend keeps the API key server-side; editorial-style UI; capped at 2,500 characters per conversion to conserve API credits.
